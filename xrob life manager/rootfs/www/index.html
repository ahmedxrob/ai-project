Settings & integrations

Connect Telegram and Home Assistant.

Telegram bot

Configure your bot token and allowed chat ID in the Home Assistant add-on configuration, then restart the add-on.

/start · /today · /tasks · /bills
/weight 89.5 · /task Buy groceries · /naildone

The first MVP supports explicit commands. Natural-language AI is disabled as requested.

Home Assistant integration

Install the companion custom integration from the project folder. Configure the API URL as http://HOME_ASSISTANT_IP:8090.

GET /api/ha/state
GET /api/summary
GET /api/health

Data and privacy

All records are stored in /config/xrob_life_manager.db inside the add-on persistent configuration mount. Back up the Home Assistant add-on configuration regularly.

No Google Calendar, cloud database or Ollama connection is used.
