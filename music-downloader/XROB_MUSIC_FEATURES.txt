RELIABILITY
- yt-dlp is invoked through the same Python environment as Xrob Music.
- FFmpeg is resolved from the container PATH.
- Server validates settings before saving them.
- Library refresh invalidates metadata caches.
- Tracks/artists/albums are returned from the same catalog model.
- Download task state is stored on the local /data volume.
- Network-library disconnection is detected instead of silently appearing as an empty library.
- Temporary download files are excluded from the library.

NOTES
- Xrob Music does not create public Internet access by itself.
- External OpenSubsonic clients need a reachable server address/tunnel.
- Only download content you are authorized to download.


## 2.9.0 UI/performance update
- Startup renders the cached library immediately and loads library/settings/editor/tasks/stats/home in parallel.
- Login remembers the username locally, disables the submit button during authentication, focuses the form automatically, and uses the site session cookie.
- Account credentials can be changed in Settings.
- Up Next queue remains the source of truth for library playback and guards invalid queue indexes.
- Artist cards support custom artist cover uploads.
- Settings Library status reports tracks, albums, artists, total play count and total track size.


## 2.9.2 QUEUE / UI FIXES
- Global Shuffle and Library Shuffle now use the same playback queue that Up Next displays.
- Next and automatic ended playback advance by queue index instead of generating a different random track.
- Shuffle keeps the current track fixed and shuffles the remaining tracks.
- Turning Shuffle off restores the queue order that existed when shuffle was enabled.
- Up Next queue editing keeps the current track/index synchronized with playback.
- Clear Queue keeps the currently playing library track and removes upcoming tracks only.
- Current queue item cannot be removed while it is playing, preventing invalid playback state.
- Queue, dialog and mobile-player layering were corrected to avoid controls being hidden behind the player or bottom navigation.


## Songs Editor / UI polish update

- Songs Editor review list contains only tracks still in `pending` review state.
- The existing-track selector now lists only library tracks whose review state is `edited`, allowing a previously edited song to be reopened without showing all pending/new songs.
- Reopening an edited track returns it to the pending review queue, where it can be edited again normally.
- Replaced inconsistent emoji/text controls in the enhanced queue, library track actions, playlists, search/close controls, and empty states with the app’s local Lucide-style SVG icon system.
- Improved queue drawer, modal surfaces, icon buttons, editor search controls, empty states, and mobile spacing while preserving existing functionality.


## 2.9.2 CURRENT FIXES
- Home dashboard uses Total Plays instead of Active Downloads.
- Live library counters update without transient resets to zero when a response is incomplete or not ready.
- Play count updates immediately after a track play is recorded.
- Track, artist, album and storage statistics are shared through one live-stat state in the UI.
- Newly selected tracks always start from 0:00; previously saved per-track positions are not restored when selecting a track again.
- Download completion triggers a live statistics/home refresh so library counters update without a full-page reload.
