XROB MUSIC 2.9.3
Complete verified feature list

HOME
- Real Tracks / Artists / Albums counters from the scanned library.
- Recently Added tracks with playback.
- Download shortcut.
- Active download status.
- Recently Added playback queue with synchronized Previous / Next behavior.

SEARCH & DOWNLOAD
- YouTube search through yt-dlp.
- Audio-only downloads.
- MP3, FLAC, M4A, OPUS and supported container formats.
- Configurable lossy quality.
- Preview before downloading.
- Download queue with live progress.
- Cancel, retry and clear completed tasks.
- Persistent task state.
- Metadata and artwork options.
- Optional artist-folder organization.

LIBRARY
- Recursive scan of the configured music folder.
- MP3, FLAC, M4A, OGG, WAV, OPUS, AAC and ALAC cataloging.
- Metadata from embedded tags with filename/folder fallback.
- Tracks / Artists / Albums views.
- Artist detail pages with albums and tracks.
- Album detail pages with tracks.
- Search across the active library view.
- Play track, Play all, Play album and Play artist.
- Library shuffle with a real shuffled queue rather than a new random choice for every Next action.
- Shuffle state is synchronized with the global player and Up Next queue.
- Previous / Next playback follows the same queue and index.
- Repeat Off / Track / Queue.
- Queue drawer with current-track highlighting.
- Drag-to-reorder queue.
- Play-next queue action.
- Remove upcoming queue items without changing the current track.
- Save the current queue as a playlist.
- Delete individual library files.
- Quick library refresh with cached metadata reuse.
- Full metadata rebuild.
- Cached catalog for faster startup and offline resilience.
- Album artwork from embedded covers.
- Storage path, free space and writable state.

PLAYER
- Persistent global player.
- Play / pause.
- Previous / next.
- Seek and volume persistence.
- Synchronized shuffle mode.
- Artwork, title and artist.
- Automatic next-track playback using the active queue.
- Queue-aware library playback.
- Playback state persistence.
- Saved playback positions.
- Play history / play counts.
- Visualizer.

SONGS EDITOR
- Tracks awaiting metadata review.
- Search by title, artist, album or filename.
- Edit title, artist and album metadata.
- Skip an editor item.
- Re-add all library tracks to the editor for a complete re-review.
- Import one existing library track back into the editor.
- Live editor queue count and navigation badge.
- Responsive editor cards and controls.

SETTINGS
Only settings that change download behavior are exposed:
- Download format.
- Download quality for lossy formats.
- Write metadata on/off.
- Embed artwork on/off.
- Artist folders on/off.
- Background library scan on/off.
- Scan interval.
- Save changes.
- Reset to defaults.
- Read-only library/storage status.
- Tracks, albums, artists, total plays and total track size.
- Storage usage progress bar.
- Read-only OpenSubsonic availability status.

OPENSUBSONIC / AMPERFY
- Subsonic/OpenSubsonic-compatible REST API.
- JSON and XML responses.
- Authentication.
- Music folders, artist indexes, artists, albums and directories.
- Song details and searching.
- Random songs and genres.
- Streaming and download endpoints.
- Cover art.
- Favorites/starred support.
- Playlists.
- Scrobble and now-playing endpoints.
- Similar songs.
- Lyrics endpoint.
- Stable server-side IDs.

RELIABILITY
- yt-dlp is invoked through the same Python environment as Xrob Music.
- FFmpeg is resolved from the container PATH.
- Server validates settings before saving them.
- Library refresh invalidates metadata caches.
- Tracks/artists/albums are returned from the same catalog model.
- Download task state is stored on the local /data volume.
- Network-library disconnection is detected instead of silently appearing as an empty library.
- Temporary download files are excluded from the library.
- Global player controls and Up Next now use one synchronized queue model for library playback.
- Shuffle preserves the currently playing track, then randomizes the remaining queue.
- Disabling Shuffle restores the natural queue order for the active library/home queue where available.

PERFORMANCE
- Startup renders the cached library immediately.
- Library, settings, editor, download tasks, stats and home data load in parallel.
- Quick Scan avoids duplicate event handlers.
- Quick Scan reuses cached metadata whenever possible.
- Full scan metadata work is parallelized.
- Library index is persisted for faster subsequent startup and refreshes.
- Songs Editor renders with browser content visibility optimization for larger queues.

UI / VISUAL
- Consistent control heights, icon sizing and button alignment.
- Responsive library statistics cards.
- Responsive Songs Editor toolbar and cards.
- Consistent Settings library status cards.
- Storage capacity progress bar.
- Improved Up Next queue spacing and mobile layout.
- Library and editor badges display plain numbers instead of parenthesized counts.

NOTES
- Xrob Music does not create public Internet access by itself.
- External OpenSubsonic clients need a reachable server address/tunnel.
- Only download content you are authorized to download.
